## 申报

```mermaid
sequenceDiagram
    participant Teacher as 教师
    participant DepartmentHead as 申报部门负责人
    participant SchoolLeader as 学校负责人
    participant AcademicOffice as 教务处(西教四楼)

    Teacher->>Teacher: 1. 填写审批表，签名“申请人”
    Teacher->>DepartmentHead: 2. 提交材料
    DepartmentHead-->>Teacher: 3. 审批并签名
    Teacher->>SchoolLeader: 4. 提交材料
    SchoolLeader-->>Teacher: 5. 签名
```

预算金额应为价格浮动留有余地（验收总额≤预算金额）

:::

## 采购

:::danger

购买前应确认是否能开发票。

发票上必须要显示的内容：单位税号（纳税人识别号）、单价、数量

:::

:::note 注意事项

需以 pdf 格式打印发票，不能用图片打印。

普通发票或专用发票都可以。专用发票展示信息更全，不过不是每个店铺都愿意开专用发票。

可将发票发送到邮箱，方便打印。

:::

## 验收

```mermaid
graph LR;
    filling(教师填写验收表)-->signature(三位教师签名);
    signature-->reimbursement(去财务处走剩余报销流程);
```

:::danger

表格中的项目与数量，一定要与发票相符。

:::

验收表填写示例：

- 填写：日期、表格内容
- 留空：其他内容（批复编号、申报部门、金额单位等）

| 序号 | 采购项目名称 | 品牌 | 数量 |
| :---: | :--- | :--- | :---: |
| 1 | 水火箭尾翼 | 七波 | 8 |
| 2 | 电工胶带 | 七波 | 8 |

- 验收人：**三位**老师签名

:::info 【验收表】由【审批表】修改而来

- 抬头：“申报审批表”改成“申报验收表”；
- 删除表格三列：“规格及技术参数”、“预算单价”、“预算金额”；
- 删除表格整行：采购金额合计（大写）：___ 元；小写：¥ __.__；
- 修改:“申请人”改成 **“验收人”**，三位老师签名；
- 删除表格内容：**“申报部门负责人：”**、**“联系电话：”**；
- 删除表格单元格：**“校长办公室审批意见：”** 所在单元格

:::

## 报销

```mermaid
sequenceDiagram
    participant Teacher as 教师
    participant Accountant as Liu Weiling （西教学楼一楼财务室）
    participant Chair as 领导

    Teacher->>Accountant: 1. 带申报表、验收表、发票
    Accountant-->>Teacher: 2. 发放“支出凭单”
    Teacher->>Teacher: 3. 填写凭单
    Teacher->>Teacher: 4. 签名(经手人)
    Teacher->>Chair: 5. 提交凭单请领导签字
    Chair->>Teacher: 6. 签名(“证明人”、“领导批准”)
    Teacher->>Accountant: 7. 将全部材料交给财务
```
